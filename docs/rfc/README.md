# RFCs — Tech Challenge Fase 3

RFCs (*Request for Comments*) registram as **decisões de arquitetura do sistema como um todo** —
propostas discutidas antes de implementar, com contexto, alternativas e consequências.
Decisões locais de cada repositório ficam nos respectivos **ADRs** (`docs/adr/`).

| [0002](0002-autenticacao-cpf-jwt-serverless.md) | Autenticação por CPF via serviço serverless | Aceita |
| [0003](0003-nuvem-real-railway-e-banco-gerenciado.md) | Nuvem real (Railway) + banco gerenciado + cluster Kubernetes | Aceita |
| [0004](0004-observabilidade-newrelic.md) | Observabilidade unificada com New Relic | Aceita |
