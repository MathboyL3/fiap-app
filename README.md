# fiap-app

Aplicação principal (API .NET, Clean Architecture) da oficina, executada no Kubernetes e observada via **New Relic**. Parte do Tech Challenge Fase 3 (SOAT/FIAP).

## Tecnologias
- .NET (ASP.NET Core, Clean Architecture)
- PostgreSQL (banco gerenciado Railway)
- New Relic (APM + logs + dashboards)
- Docker + Kubernetes
